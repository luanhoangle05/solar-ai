# SYNTHETIC EXAMPLE DATA — simulated, not measured

`example_weather.csv` is generated by `scripts/generate_example_data.py` from the
formula below. No value in it was fetched from a weather provider or measured on a
panel. It exists only so models, the optimizer and the agents can be developed
before Luan's real pipeline output is available.

**Labeling rule:** anything built on this file uses `dataset_kind = "MOCK"` and
`label_source = "mock"`. Metrics computed on it describe how well a model learned
this formula. They are not evidence of real-world accuracy or energy savings.

## Contents

- 4416 hourly rows, `2026-03-01T00:00:00Z` to `2026-08-31T23:00:00Z` (UTC).
- Exact 13-column `WEATHER_COLUMNS` header; every row passes `validate_weather_row`.
- `timestamp` is the start of the one-hour interval. Sun position is taken at the
  middle of the interval.
- `actual_kwh` is energy for one 20-panel row over that hour.
- `panel_angle_deg` is drawn independently each hour from 0, 5, ..., 90 so that
  models can learn how tilt changes energy. A real tracker would not move like this.

## Regenerate

```powershell
.\.venv\Scripts\python.exe -m scripts.generate_example_data
```

The seed is fixed (`20261004`), so the output is identical on every run. A test
checks that the committed CSV equals the generator output.

## Assumptions (hypothetical site, not a surveyed farm)

| Assumption | Value |
| --- | --- |
| Latitude / longitude | 52.0 / -113.0 degrees |
| Panel azimuth | 180 degrees (faces south); tilt = `panel_angle_deg` from horizontal |
| Panel rating | 0.35 kW at 1000 W/m2, 20 panels per row (7 kW per row) |
| System efficiency | 0.9 |
| Temperature coefficient | -0.4 % per degree C of cell temperature above 25 C |
| NOCT | 45 C |
| Ground albedo | 0.2 |
| Label noise | Gaussian, 3 % of the noise-free energy |

Every coefficient is a field of `ExampleDataConfig` in the generator.

## Formula

**Sun position** — NOAA low-accuracy equations (declination and equation of time
from the day of year, hour angle from UTC time and longitude). Azimuth is clockwise
from north.

**Weather** — random but persistent:

- Cloud cover: a daily level (Beta(0.8, 1) draw, half carried over from the previous
  day) plus hourly Gaussian noise (sigma 12 points), clamped to 0..100.
- Temperature: seasonal cosine (mean 8 C, amplitude 10 C, warmest on day 200) plus a
  diurnal cosine (amplitude 6 C, warmest at 15:00 solar time), minus up to 3 C of
  daytime cloud cooling, plus Gaussian noise (sigma 1 C).
- Wind: a daily mean (Gamma(4, 3.5) km/h; 4 % of days are storm days with +35 km/h)
  times hourly noise. Gust = wind x a factor between 1.3 and 1.8, never below wind.
- Precipitation: when cloud cover exceeds 75 %, 35 % chance of rain with an
  exponential amount (mean 1.5 mm); otherwise 0.

**Irradiance** (all zero when the sun is at or below the horizon), with
`c = cloud_cover_pct / 100` and `el` = sun elevation:

```text
air_mass  = 1 / (sin(el) + 0.50572 * (el_deg + 6.07995) ^ -1.6364)
clear_dni = 1361 * 0.7 ^ (air_mass ^ 0.678)
clear_dhi = 0.1 * 1361 * sin(el)
clear_ghi = clear_dni * sin(el) + clear_dhi
ghi       = clear_ghi * (1 - 0.75 * c ^ 3.4)
dni       = clear_dni * (1 - c) ^ 1.2
dhi       = ghi - dni * sin(el)
```

**Irradiance on the tilted panel**, with `t` = `panel_angle_deg`:

```text
cos_incidence = sin(el) * cos(t) + cos(el) * sin(t) * cos(sun_azimuth - 180)
poa = dni * max(0, cos_incidence)
    + dhi * (1 + cos(t)) / 2
    + ghi * 0.2 * (1 - cos(t)) / 2
```

**Energy label:**

```text
cell_temp  = temperature_c + poa * (45 - 20) / 800
power_kw   = 7 * (poa / 1000) * 0.9 * (1 - 0.004 * (cell_temp - 25))
actual_kwh = max(0, power_kw * 1 h * (1 + noise)),   noise ~ Normal(0, 0.03)
```

The label is computed from the rounded feature values written to the CSV, so the
file alone reproduces `actual_kwh` up to the noise term.

## Known limitations

- No row-to-row shading, soiling, inverter clipping, snow or panel faults.
- The clear-sky and cloud models are simple approximations, not pvlib.
- Wind, rain and temperature do not affect each other beyond what is listed above.
- Hourly random tilt means consecutive rows are not a realistic tracker history.
