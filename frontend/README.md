# SolarAI Frontend

Frontend application for the SolarAI AI-powered solar farm optimization project.

## Phase 0

Phase 0 establishes the frontend engineering foundation only. It does not yet consume the SolarAI backend or mock-data contract.

## Stack

- Next.js
- React
- TypeScript
- App Router
- Tailwind CSS
- shadcn/ui-compatible component structure
- Lucide React
- Recharts
- Zod

## Development

Install dependencies:

```bash
npm install
```

Start development:

```bash
npm run dev
```

Lint:

```bash
npm run lint
```

Production build:

```bash
npm run build
```
